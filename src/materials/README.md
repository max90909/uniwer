# Файлы для учеников

Всё, что вы положите в эту папку, ученики увидят на странице «Обучение»
в блоке «Файлы от преподавателя» и смогут скачать.

## Как добавить файл

1. Скопируйте файл в эту папку (`src/materials/`).
2. Закоммитьте и запушьте:

       git add src/materials
       git commit -m "Материалы: добавлен конспект недели 3"
       git push

3. Через минуту-две GitHub Pages пересоберёт сайт, и файл появится у учеников.

Список нигде вести не нужно — он собирается автоматически на сборке.
Имя файла показывается ученикам как есть, поэтому называйте понятно:
`Неделя-03-конспект.pdf`, а не `doc1.pdf`.

## Что учитывать

- Файлы лежат в репозитории, поэтому это для методичек, заданий и аудио —
  не для тяжёлого видео. GitHub предупреждает на файлах больше 50 МБ и
  отказывается принимать больше 100 МБ.
- Файлы публичные: ссылку сможет открыть любой, у кого она есть.
  Не кладите сюда персональные данные и ответы к контрольным.
- Этот README ученикам не показывается.
